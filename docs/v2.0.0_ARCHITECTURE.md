# REMoAINTER v2.0.0 Architecture & Technical Specification

REMoAINTER is a next-generation, high-performance open-source 3D PBR texture painting suite engineered to match the industry-standard workflow, UI layout, and architectural paradigm of **Adobe Substance 3D Painter**.

Version `v2.0.0` introduces a high-throughput **Rust Core Engine** utilizing multi-core parallelism via `rayon`, safe zero-copy memory abstractions, integrated mesh map baking, black mask sub-stacks, and procedural anchor points.

## 2. Mesh Maps Baking Engine (`baker::engine`)

Procedural texturing, edge wear, dirt crevices, and smart materials require baked geometric surface maps. REMoAINTER v2.0.0 includes a CPU-based multi-threaded baker accelerated with `rayon`.

### Supported Bake Channels

| Map Type | Resolution | Algorithm | Substance Painter Parity |
| :--- | :--- | :--- | :--- |
| **Ambient Occlusion (AO)** | Up to 4096² | Cosine-weighted hemispherical ray casting (8 to 128 rays/pixel) testing ray-triangle intersection | Replaces costly GPU bake requirements on non-RTX systems |
| **Curvature** | Up to 4096² | Surface Laplacian normal differential across mesh vertices, identifying convex edges and concave crevices | Drives edge-wear generators and smart masks |
| **World Space Normals** | Up to 4096² | Vector orientation mapped to RGB color channels `[x*0.5+0.5, y*0.5+0.5, z*0.5+0.5]` | Used for directional weathering (e.g. top-down dust) |
| **Tangent Space Normals**| Up to 4096² | Flat blue tangent base `(128, 128, 255)` ready for high-poly to low-poly micro-surface details | Standard PBR normal map format |
| **Position** | Up to 4096² | Normalized 3D position vectors in object bounding box `[0..1]` | Used for vertical gradients and ground dirt |
| **Thickness** | Up to 4096² | Inverse normal raycast measuring mesh interior distance | Powers subsurface scattering and translucency |
| **ID Map** | Up to 4096² | Unique color hashing per polygon / smoothing group / material ID | Allows color-selection masking |

### Selective vs. Full Baking

REMoAINTER allows texturing artists to:
- **Bake All Mesh Maps**: One-click parallel execution producing all 7 maps simultaneously with real-time atomic progress reporting.
- **Selective Map Baking**: Re-bake only a single map (such as Ambient Occlusion at higher ray samples) without having to recompute unchanged maps.

## 3. Black Masks & Mask Sub-Stack Architecture (`painting::mask`)

Substance Painter's signature texturing method is layering uniform materials (e.g., rusted steel, oxidized bronze, scratched paint) and masking them using procedural effects.

### Mask Types
- **White Mask (Value 1.0)**: Layer completely reveals itself.
- **Black Mask (Value 0.0)**: Layer is fully concealed until mask effects are stacked.

### Sub-Stack Effects
Within any mask, users can add an ordered stack of non-destructive procedural modifiers:
1. **Fill Effect**: Injects a procedural noise generator (e.g., Perlin/Simplex grunge) with controllable frequency and contrast.
2. **Paint Effect**: Allows freeform brush painting directly into the mask buffer.
3. **Generator (Edge Wear / Dirt / Crevice)**: Reads the baked **Curvature** and **AO** maps to dynamically create realistic edge chipping and dirt accumulation.
4. **Levels**: Adjusts Black In, White In, Midtone Gamma, Black Out, and White Out.
5. **Invert**: Flips mask values `(1.0 - x)`.

Sub-stack blending modes include:
- `Normal` (Replace)
- `Multiply`
- `LinearAdd`
- `Subtract`
- `Max` / `Min`

## 4. Anchor Points (`painting::anchor`)

Anchor Points solve complex cross-layer dependencies by allowing any layer or mask output to be referenced as an input by a higher layer or generator in the stack.

- **Anchor ID & Name**: Unique identifier (e.g., `"Base_Height_Details"`).
- **Target Channel**: References either the composite Layer output or its specific Mask channel.
- **Referenced Consumption**: Generators higher in the hierarchy can sample the anchor's height/mask values to automatically generate micro-wear on newly stamped height details.

## 5. Toroidal Seam Boundary Wrapping & Brush Engine (`painting::brush`)

A persistent challenge in 3D painting across UV layouts is seam cracking—where brush strokes stop abruptly at UV boundaries or cause harsh lines.

REMoAINTER implements **Toroidal UV Wrapping**:
- When a brush dab is applied near texture coordinates `(u, v)` adjacent to 0.0 or 1.0 borders, the brush kernel automatically calculates wrapped coordinates:
  $$u_{wrapped} = (u \pm \text{radius}) \pmod{1.0}$$
  $$v_{wrapped} = (v \pm \text{radius}) \pmod{1.0}$$
- Stamping evaluates boundary cross-sections seamlessly across UV seams.
- **Alpha Mask Falloffs**: Soft Round, Gaussian, Dirt, Grunge, Concrete, and Scratches.
- **Lazy Mouse**: Directional smoothing vector filters mouse trembling for crisp lines.
